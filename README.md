# Еда в Яндекс Go · Presentation System

Пакет для создания презентаций по брифу в согласованной дизайн-системе. Версия 1.0, снимок Figma от 19 ноября 2026.

## Для коллеги

1. Откройте чат с AI, умеющим читать файлы и создавать PPTX. Загрузите этот архив целиком либо дайте доступ к репозиторию.
2. Скопируйте `PROMPT.md`, заполните `BRIEF.md`, приложите свои таблицы и фотографии.
3. Получите PPTX и PDF. Установите шрифты из отдельных архивов перед редактированием PPTX.
4. Проверьте факты и числа. Не используйте демонстрационные показатели из примеров как реальные.

Обычный текстовый чат без инструментов создания файлов не сможет выполнить сборку. Сам GitHub презентации не генерирует.

## Что внутри

- `DESIGN-RULES.md` — обязательные правила, включая исключения для обложки и телефона навылет.
- `LAYOUTS.md`, `layouts.json`, `catalog.html` — 20 макетов сборщика, ограничения, превью и ссылки на исходники.
- `figma-catalog.json` — полный индекс 83 исходных макетов Figma. Остальные 63 доступны как ссылки-референсы; автоматический сборщик пока реализует только 20 макетов v1.
- `assets/brand/` — SVG-исходники и прозрачные PNG для надёжного экспорта логотипа и спирали; `assets/food/` — подготовленные фотографии высокого разрешения.
- `fonts/` — YS Display Cond Black, YS Text Regular/Medium и архивы отдельно по семействам.
- `presentation.tokens.json`, `brief.schema.json` — машинные параметры и формат брифа.
- `scripts/` — валидатор брифа, сборка редактируемого PPTX и PDF, проверка пакета.
- `examples/catalog.json` — демонстрация всех 20 макетов. `examples/brief.json` — короткий пример обычной презентации.
- `templates/` — собранный редактируемый каталог PPTX, его PDF и превью.
- `AGENTS.md`, `PROMPT.md`, `QA.md` — инструкции для AI и критерии приёмки.

## Статус и точность

Figma — визуальный источник; PPTX — адаптация для PowerPoint, а не побайтовый экспорт Figma. Упрощены технические заглушки: серый фон и надпись вместо диагонального паттерна. Фотографии и фирменная графика — изображения; текст, панели, рамки, таблицы и графики остаются редактируемыми объектами.

Файлы не обновляются при правках в Figma автоматически. Порядок синхронизации — в `MAINTENANCE.md`.

## Локальная сборка

См. `SETUP.md`. Проверенный путь — Codex с установленным runtime `@oai/artifact-tool`.

```sh
node scripts/validate.mjs examples/catalog.json
node scripts/build.mjs examples/brief.json output/my-presentation
```

Результат: `.pptx`, `.pdf`, PNG-превью, JSON геометрии и отчёт сборки. Сборщик не вызывает AI: бриф в JSON подготавливает AI по текстовому брифу человека.

## Размещение

Пакет подготовлен локально; репозиторий и сайт не созданы и не опубликованы. Для внутреннего репозитория используйте `PUBLISHING.md`. Пакет не предоставляет новых прав на фирменные материалы и шрифты.

PDF в приложенном каталоге — растровый снимок финальной модели 1920×1080: внешний вид шрифтов сохранён, текст PDF не выделяется. PPTX содержит редактируемые объекты и встроенные книги данных диаграмм.

Текущая версия: 1.0.1 (24 ноября 2026). Исправления тестовой презентации перенесены в общий сборщик.
