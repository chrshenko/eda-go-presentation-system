# Как передать коллегам

1. Создать репозиторий `eda-go-presentation-system` в выбранном рабочем аккаунте GitHub. До публикации определить доступ к фирменным файлам и шрифтам.
2. Загрузить содержимое пакета, исключив node_modules, временные выходы и локальные ключи. В репозитории не должно быть секретов.
3. Для публичного репозитория не добавлять шрифты и материалы, права на публичную раздачу которых не подтверждены. .gitignore уже исключает бинарные шрифты и ZIP; передавать их по разрешённому внутреннему каналу.
4. В README и PROMPT заменить [ВСТАВИТЬ ССЫЛКУ] на URL репозитория. Указать способ получения шрифтов и доступ к Figma.
5. Добавить каталог PPTX/PDF и превью в release v1.0.1. Дать коллегам ссылку и готовый PROMPT.md.
6. Прогнать один новый бриф с чистого чата и проверить выдачу файлов. Наличие README на GitHub само по себе не доказывает, что любой AI сможет создать PPTX.

Этот пакет не создаёт репозиторий, не публикует файлы и не запускает платные сервисы.
